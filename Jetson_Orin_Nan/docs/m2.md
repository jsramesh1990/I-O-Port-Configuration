# M.2 Interface

## Overview

The Jetson Orin Nano features an M.2 M-key slot for NVMe SSDs and other PCIe devices.

## Specifications

| Parameter | Value |
|-----------|-------|
| Key Type | M-key |
| PCIe Lanes | x4 (Gen3) |
| Supported Devices | NVMe SSD, AI accelerators |
| Form Factors | 2242, 2280 |
| Power | 3.3V up to 3A |

## Implementation

```cpp
class M2Device {
private:
    PCIeScanner scanner;
    
public:
    bool detectNVMe() {
        scanner.scan();
        PCIeScanner::PCIDevice nvme;
        
        // NVMe class code: 0x0108
        if(scanner.findDevice(0x144D, 0x0000, nvme)) {  // Samsung example
            printf("NVMe SSD detected\n");
            return true;
        }
        return false;
    }
    
    std::string getNVMeModel() {
        // Read from sysfs
        std::ifstream model("/sys/class/nvme/nvme0/model");
        std::string model_str;
        std::getline(model, model_str);
        return model_str;
    }
    
    bool enableASPM() {
        // Enable Active State Power Management for power saving
        std::ofstream aspm("/sys/bus/pci/devices/0000:01:00.0/power/control");
        aspm << "auto";
        return true;
    }
};
```

## Best Practices for M.2

1. **Use heatsink** for NVMe drives
2. **Monitor temperature**: `nvme smart-log /dev/nvme0`
3. **Enable PCIe ASPM** for power saving
4. **Check link speed**: `lspci -vvv -s 01:00.0 | grep LnkSta`
5. **Use TRIM** for SSD health: `fstrim -v /mnt/nvme`
